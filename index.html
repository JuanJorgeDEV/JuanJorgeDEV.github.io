G-Lab - Gestão de Ordens de Serviço
Projeto Integrador Deploy: Render

Sistema web para gerenciar ordens de serviço de equipamentos em laboratórios e salas de aula. Centraliza o suporte técnico, evita a abertura de chamados duplicados para o mesmo equipamento e equilibra a carga de trabalho entre técnicos, limitando a execução a uma tarefa ativa por vez. Cronometra o tempo líquido gasto em cada serviço, pausando automaticamente em períodos de espera. Conta com controle de acesso por papéis (Administrador / Colaborador), cadastro e histórico de equipamentos e abertura inteligente de OS com autocomplete via AJAX.

ASP.NET Core MVC (.NET 10) EF Core PostgreSQL (Supabase) Razor + Bootstrap AJAX
